# Circuito de Descobertas — app do visitante

App Flutter, somente Android (`applicationId` `com.circuitodescobertas.app`). Instruções de execução no [README da raiz](../README.md).

```text
lib/
├── main.dart
├── app/            # MaterialApp e tema (theme/: cores, tipografia e medidas dos tokens)
├── core/           # constants/ (contrato de dados), analytics/, widgets/
└── features/       # auth, estandes, checkin, missao — cada uma com data/ e presentation/
```
